# Manuály k aplikaci ProArchiv17

Aplikace ProArchiv17 nabízí na těchto stránkách komplexní souhrn informací potřebných pro zdárné zvládnutí pořádacích prací v této nové aplikaci za použití nových Základních pravidel pro pořádání (dále jen ZP).

*Uživatelská příručka k aplikaci ProArchiv17 je postupně doplňována!*
